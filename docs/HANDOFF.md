# Продолжение · 0.7.1

Добавлены шесть стандартных и несколько пользовательских пресетов: appearance-presets.js (нормализация и шаблоны), appearance.js (выбор, создание, обновление по тому же имени, удаление, localStorage). Material/Glass мигрируют из прежних ключей. Смена пресета применяется ко всем параметрам одним действием.

Системный Windows titlebar overlay заменён локальными кнопками окна с guarded IPC. Все кнопки имеют согласованную геометрию, hover не растягивает caption на 72px. Светлая тема меняет и Electron nativeTheme, system сохраняет системный режим.

presentation.cjs синхронизирует dark/light, glass и opacity в remote Music при изменении оформления и новой загрузке. Непрозрачный материал, Glass off и opacity 0 отключают blur обеих шапок. Светлая тема явно исправляет текст, иконки и поля YouTube, а также локальные вторичные подписи/визуализатор.

Важная причина sharp-card leak: YouTube скроллит HTML, #content имеет небольшую собственную высоту и overflow-visible. music-preload.cjs ограничивает только отрисовку #content ниже fixed header с расширенным polygon clip-path, обновляя границу по scroll/resize. Не заменять на inset(64px): это обрежет overflow и почти весь каталог. Размеры и логика нативного player DOM не меняются. Полноэкранный DOM снимает clip.

Ambient теперь сохраняет три различающихся оттенка из обложки (artworkPalette), а не один тон. Проверяется текущий videoId перед применением сетевого результата, чтобы не показывать палитру ушедшего трека.

scripts/catalog-review.cjs проверяет реальные native DOM, темы, clip и размеры; запускается node scripts/run.cjs --catalog-review. Screenshot API WebContentsView иногда возвращает прозрачные кадры или Current display surface not available; поэтому финальная визуальная проверка также проводится через computer-use на реальном окне. UI-review делает 35 кадров, включая пресеты, и 40 resize/state cases.

# Состояние · 0.7.0

Исправлен Google sign-in: разрешён www.youtube.com/signin, разрешённые новые окна загружаются в текущую изолированную сессию, из desktop UA убрана маркировка Electron. В настройках добавлен отдельный вход. Живая проверка открыла Google форму с input email без предупреждения о неподдерживаемом браузере; сам аккаунт без пользователя не авторизовывался.

Дополнительно: единый Windows titlebar overlay; поиск перенесён в топбар; Liquid Glass/материал перенесены в «Вид»; приглашение доступно в заголовке очереди. Навигация Music пропускает about:blank, login handoffs и дубли; TV forward отключён, back — Escape.

immersion.js: автоскрытие dock с восстановлением у нижнего края/по клику на фон; реально услышанный waveform «След» (не заполняет перемотанные участки), волна/спектр/орбита; мягкие/дымка/призма/частицы текста. 48 спектральных полос IPC валидируются, движение учитывает prefers-reduced-motion. Палитры альбом/серебро/нуар, скорость движения фона; монохромные обложки больше не получают янтарную подстановку. Фон artwork воссоздан по визуальному принципу TV; нативный движок YouTube не скопирован.

appearance.js/css: нейтральный старт, акцент из обложки, общая подложка очереди, текстовое меню «Вид» (тема, прозрачность, ambient/плавающая обложка/спокойный фон, зерно). Настройки сохраняются в localStorage. При открытии меню над нативным каталогом для него резервируется боковая полоса: WebContentsView нельзя перекрыть DOM-поповером.

Убраны топбарное приглашение, декоративный футер и подпись очереди. Полноэкранная навигация — отдельные приглушённые кнопки. Пустой dock скрыт; в настройках dock не показывается и main не резервирует его высоту. Селекты и кнопки стеклянные. Native Music header сильнее размыт; focused search больше не получает чёрную подложку.

Custom NSIS installer позволяет выбрать папку без записи uninstall-реестра/ярлыков. Маркер self-contained включает data рядом с EXE для userData/sessionData/logs/temp/crashDumps. Uninstall оставляет data. updates.cjs проверяет стабильные GitHub releases, SHA256SUMS, скачивает в data/updates; установка ждёт PID приложения и перезапускает его. Проверка релизов автоматическая, установка по кнопке. Подписи сертификатом нет; реальный переход между двумя опубликованными версиями ещё требует последующего релиза.

Android не изменяли по прямому указанию пользователя. Подтверждён upstream ABI bug: NativeQueueList имеет addListener(), installer генерирует addListener(Object) и removeListener(Object). Краш из пользовательского лога соответствует этому. Не пытаться скрывать его изменением криптографии/протокола десктопа.

TV: общий локальный экран с винилом/текстом/контролами, отдельный нативный каталог YouTube TV. При недоступной очереди реальное nowPlaying передаётся отдельно, items не выдумываются; пауза работает по текущему videoId. CSS object-fit:contain для ultrawide. Живая проверка подтвердила доступность общего экрана; физический Cast и полная очередь требуют отдельного подтверждения. Music остаётся основным режимом.

Проверки: синтаксис, unit/integration, offline smoke, UI review с 40 размерами/состояниями и дополнительными проверками конца настроек/меню «Вид». Live Music подтвердил ADD/REMOVE реальной очереди, Explicit, 77 строк текста, 1280px обложку, background playback, audioLevel ~0.99 и форму входа Google. Иногда desktop capture недоступен; только такие снимки пропускаются, функциональные проверки продолжаются. Offscreen UI-review остаётся обязательным.

## Задача и принятые решения

Пользователь просит стеклянный музыкальный клиент с реальной общей очередью, центральными текстами и винилом. Полный список текущего прохода: монохромный знак с прозрачной спиралью; тёплый оранжево-янтарный вихрь с небольшим фиолетовым акцентом при старте; прозрачные верхние кнопки; плавные фон/трек/панели; контекстные иконки текста и очереди справа в нижнем плеере; hover-панели; русский Ctrl K; fullscreen-навигация; drag & drop; ограничения гостей; постоянный фильтр E; понятное поведение кнопки Cast; README с медиа и документация отдельно.

Не возвращать независимые WebContentsViews для текста/очереди и не менять геометрию приватного player DOM YouTube: это вызывало наложения, размытые обложки и обрезку. Размер обложки зависит от доступной высоты контейнера, а не только viewport. Центральный текст должен центрироваться в реальном ограниченном scroll viewport; большие процентные padding ломали низкое окно.

## Состояние реализации

- Сцена/контролы/винил/огненная заставка и смена ambient реализованы локально.
- Серверная политика сохраняется в playback-policy.json. Default: Explicit запрещён, скрытие E включено, 3 несыгранные песни на участника, управление гостей разрешено до отключения хостом.
- Политика применена к browser и Android host-командам; actor передаётся отдельным доверенным контекстом.
- Маркировка проверяется через /music/get_queue; unknown отклоняется. Это не детектор аудиоконтента. Нативная очередь и hook страницы убирают/пропускают известные E. Проверить новые варианты badge renderer при изменениях YouTube.
- Автоматический fallback из TV в Music убран из main.cjs. Библиотечный JamPlayer всё ещё поддерживает необязательный fallback для отдельного теста; production его не устанавливает.
- Cast перехватывается в music-preload и открывает локальное объяснение; переход наружу требует нажатия пользователя. Нативного Cast sender/receiver не добавлено.
- Каталог получает прозрачные backgrounds и собственный ambient. Реальную видимость Mica/Acrylic окончательно оценивать на Windows 11 в обычном окне: offscreen снимки не воспроизводят системный backdrop.

## Проверки и ограничения

36 unit/integration tests и smoke проходят. UI review: 40 resize cases, 25 screenshots, реальные CSS/WAAPI анимации, русская раскладка, drag & drop, вращение и fullscreen. Живой прогон подтвердил TV-каталог с сохранением режима, затем явный Music, native ADD/REMOVE, 77 строк, изображение 1280px и фоновый звук с audio level около 0.99. Финальный review после изменения заставки проходит. Каталог: body и ytmusic-app имеют rgba(0,0,0,0), ambient-элемент присутствует. Отдельный живой тест подтвердил: MBJFPq2Llps имеет MUSIC_EXPLICIT_BADGE, policy отклоняет ADD до мутации. Официальные музыкальные видео могут не иметь E даже у той же песни — это ограничение метаданных, не детектор аудио.

Физический Android TV/Cast pairing остаётся непроверенным. TV редактирование очереди зависит от возможностей Leanback и не заявляется полностью рабочим. Системные разрешения Cast не заменяют отсутствующий Media Router. Нельзя обещать полное исключение ненормативной лексики: фильтруются метки сервиса; неизвестная маркировка не проходит добавление. Cookie/Android ID — идентичность участника, не защищённая аппаратная привязка.

## Дальше

1. Выполнить инструкции DEVELOPMENT.md на новом ПК, затем npm run smoke и ui:review.
2. Проверить live Music и системное стекло вручную; при возможности — реальный Android/Cast.
3. Изучать TV отдельно, не портить Music автоматическим fallback и не объявлять паритет очереди без проверки.
4. Не добавлять на README инженерный журнал: состояние разработки хранить здесь. Публичные скриншоты — только собственные fixture-текст и demo-art.

Авторизация пользователя: работать над текущим приложением, собирать и публиковать на GitHub; не переносить вход Google, API-токены или чужой профиль между ПК.

## Последние исправления после пользовательской проверки 0.6

0.6 остался неопубликованным draft без EXE: пользователь запустил локальную сборку и нашёл новые дефекты. Финальная версия — 0.6.1. Не выдавать 0.6 как готовый релиз.

- Удалены оставшиеся .background-gradient, #guide-wrapper, #mini-guide-background: они давали прямоугольный чёрный разрыв каталога при прозрачных body/app. Проверять эти элементы, а не только root computed styles.
- Удалён второй ряд TV. Каталог сохраняет mode=tv, только настройки меняют режим. История назад/вперёд и главная доступны в основной и fullscreen-навигации.
- Кнопки пластинки вынесены в cover-shell за пределы круглой маски. Hit testing проверяет оба края кнопки этикетки.
- Цветовой ambient имеет постоянную базу; на паузе только пульсация мягко затухает за 1.5s.
- Заставка использует фактическую маску спирали, тёплый градиент и небольшое упругое возвращение. UI скрыт до завершения знака; затем появляется, фон intro прозрачен.
- Текстовые символы fullscreen/настроек заменены SVG; play/pause морфит две совместимые SVG path. UI-test проверяет реальную transitionProperty=d.
- Smoke не ждёт CSS animation.finished: occlusion/невидимое окно может заморозить анимацию. Для геометрии smoke отключает startup; отдельный UI review проверяет настоящие startup/morph-анимации.
- Пользователь может держать локальный EXE открытым. Не убивать его процесс ради загрузки! Копировать EXE/SHA в artifacts/release-upload и загружать копию: PowerShell InFile открывает исходный EXE эксклюзивно и конфликтует с работающим приложением.

Каталог: нижний native player-bar — плавающее стекло с отступами 20px/15px, фон player-bar-background прозрачен. Music CSS вставляется с cssOrigin:user, чтобы important-стили YouTube не возвращали чёрную шапку при SPA-переходах.
